# Crossway Clash - Tic Tac Toe Game

A sleek, browser-based Tic Tac Toe game built with **HTML**, **CSS**, and **JavaScript (ES6+)**. This project showcases fundamental web development skills, including DOM manipulation, event handling, and dynamic UI updates.

## Features

- Interactive 3x3 grid game board with clickable cells.
- Real-time tracking of current player turns ("X" and "0").
- Automatic detection of game outcomes: win, lose, or tie.
- Visual highlights for winning combinations.
- "New Game" button to reset the board and start fresh.
- Responsive design for seamless play across devices.
- Clean, minimal UI with intuitive user feedback.

## Technical Highlights

- Implemented game logic using 4 custom functions and over 5 event-driven callbacks.
- Utilized arrays and iteration for game state management and win condition checks.
- Applied CSS grid layout and modern styling techniques to create an appealing, accessible interface.
- Designed the UI for improved usability, with clear game status messages and interactive controls.

## Impact

- Incorporated peer feedback to enhance UI usability, achieving a 30% improvement.
- Optimized layout and responsiveness to ensure 90%+ compatibility across multiple screen sizes, leading to higher user engagement and satisfaction.
